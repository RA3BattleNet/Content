# 亚欧非八人地图出生点

2026-11-10。普通八人版和随机分队版均登记到日冕池。普通版不包含分队逻辑，保留房间里的队伍及原出生点。

## 两队模式

- 随机 4v4：原 P1、P2、P3、P8 为一侧，P4、P5、P6、P7 为另一侧。
- 随机 3v3：原 P1、P2、P3 对 P4、P5、P6，P7、P8 留空。
- 七人可选 4v4，五人可选 3v3；少人一侧随机选择一位玩家，在空出的己方位置补一个主基地。

上述 `Player_N_Start` 均保留原坐标；P1 等仅表示位置标签，不固定对应实际玩家。

- 2v2v2v2：A1＋A2、B1＋B2、C1＋C2、D1＋D2。七人时，落单玩家在其区域两点各有一个主基地。
- 2v2v2：原 P1＋P6、P8＋P3、P7＋P4；P2、P5 不使用。部署与补基地均使用这些原出生点的坐标和高度。五人时，同样给落单玩家两个主基地。
- 尽量保留原队友，无法完整保留时，从拆散最少原队友的方案中随机选择。跳过选项继续保留原队伍和出生点。

可玩范围为 9500×9500，外侧另有 30 格边界。表中是可玩世界坐标，绘图或传送时不再额外减去边界。A1 的海底地形高 70，但基地应部署在地图全局海面高 200。

仅在 2v2v2v2、2v2v2 成功分队后清除精兵学院和炮塔：继续使用既有局部揭示、`NAMED_KILL` 与撤销揭示流程，避免战争迷雾残影。4v4、3v3、跳过分队及普通版均保留这些建筑。
