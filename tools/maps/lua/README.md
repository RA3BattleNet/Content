# 亚欧非 8 人随机分队

`rome_random_teams.lua` 是 `RA3BN_22442_8p_RandomTeams_1_0.map` 的
`RA3BN_AUTO_4V4_INIT` 脚本内嵌 Lua 源码（含地图配置）。每帧入口仍为
`if RA3BN4V4 then RA3BN4V4:tick() end`。目标为日冕的 Lua 4 / RA3LuaBridge；
普通版不包含分队逻辑，随机版只在 Corona 元数据中注册。

| 玩家数 | 可选方案 |
| --- | --- |
| 8 | 4v4、2v2v2v2、跳过随机分队 |
| 7 | 2v2v2v2、跳过随机分队 |
| 6 | 3v3、2v2v2、跳过随机分队 |
| 5 | 2v2v2、跳过随机分队 |
| 4 / 2 | 2v2 / 1v1、跳过随机分队 |
| 3 / 1 | 保留原队伍和出生点 |

15 秒未选择时采用第一个方案。每种方案分别枚举原盟友被分开的玩家对数最少的
分队；双人模式先枚举不重复的配对，再随机分配区域和区域内的出生点。
所有随机选择使用 `GetRandomNumber()`。七人和五人模式中唯一的落单玩家
在其区域的两点各拥有一个同类型主基地，不额外生成随行部队。

规则选择人优先采用 `<1st Human Player>` 对应的 `Player_1`～`Player_8`。
若其对应观察员或其他脚本名，则按编号升序查找首个满足
`PLAYER_IS_HUMAN_OR_AI_PERSONALITY(..., "Human")` 的 `Player_X`。
AI 和观察员不接管按钮；没有匹配人类玩家时不显示弹窗，保留原安排并解锁建造。
按钮回调只接受最终选定的选择人。冬日对决和 Magmagma 随机版使用同样规则。

双人区域：A = A1 + O6，B = B1 + O8，C = O3 + O4，D = O5 + O7。
三队时使用 A、B、O5 + O4。O1…O8 对应原地图的 `Player_N_Start`。
新增 `RA3BN_Random_A1`（2150,6650，海面高 200）和
`RA3BN_Random_B1`（5075,6500，地面高 280）。C1 保留原 O3。
4v4 / 3v3 等两队模式继续使用原出生点。

Lua 通过 Waypoint 查询 XY。该接口返回的 Z 为零，因此配置保存了实测地形高度。
主基地用 `CONYARDS` / `MCVS` 注册集识别，新增基地类型用 `IncludeThing`
ObjectFilter 匹配逻辑等价类型；不调用 `ObjectTemplateName`。支持盟军、苏联、
帝国、神州的建造场和 MCV；无法匹配时恢复开局状态。

移动只涉及地图范围内、原基地附近的开局对象。暂存点彼此相距至少 3000；
移动后等待一帧，再通过地图中已确认存在的独立 `PlyrCivilian` 调用
`MAP_SHROUD_ALL`，清空待处理的旧视野。部署失败时删除新生成的额外基地，
恢复原位置及拆开的盟友关系，并解锁建造。

部署成功、关系设置完毕后，使用 `PLAYER_CAMERA_MOVE_TO_NAMED` 将每位玩家的
镜头立即移到其原主基地的新位置；传入对象引用，不给原基地增加脚本命名。
双基地玩家看向原主基地。跳过分队或部署失败时不移动镜头。
冬日对决和 Magmagma 的随机版采用相同的镜头处理，对应源码为
`winter_random_teams.lua` 和 `magma_random_teams.lua`。

### 双人分组模式的地图物体（2026-11-08）

当前亚欧非地图的 `ObjectsList` 含 15 个 `FI_FloatingFortressMainGun` 和
2 个 `VeterancyTechStructure`。随机版选择 2v2v2／2v2v2v2 后，在全部基地
成功部署、额外基地创建及阵营关系设置完成后，用 `IncludeThing` ObjectFilter
和 `ObjectFindObjects(nil, nil, filter)` 查找两类物体，逐个执行 `NAMED_KILL`。
过滤不限制归属，也不依赖 `ObjectTemplateName` 或物体的脚本名称。

两队随机模式、跳过随机分队及部署失败回滚均保留这些物体。普通版地图未修改。
地图修改仍仅涉及内嵌 Lua，`ObjectsList`、`SidesList` 及其余块
保持逐字节一致。此次随机版 CRC 为 `167644167`，Corona 元数据已重新编译。

`741c20167fe99ff8f1478556a073748e7017a70a32795b0e4bc8b4d9b4a9f268`。
